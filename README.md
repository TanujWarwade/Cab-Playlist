# Cab-Playlist

A modern web application for Cab Playlist built with React, Vite, and Tailwind CSS.

## Features

- Dynamic playlist and music player interface
- Interactive controls and smooth animations
- Built with React 19, Vite, and Tailwind CSS

## Getting Started

### Prerequisites

- Node.js (v18+ recommended)
- npm

### Installation

```bash
npm install
```

### Running Locally

```bash
npm run dev
```

### Build

```bash
npm run build
```
